# Swap App

The Swap App is GatorOS's primary DeFi trading interface, providing access to multiple DEX aggregators for optimal token swaps on the Avalanche network.

## Features

### Multi-Aggregator Support
- **Paraswap**: Advanced routing for best prices
- **Odos**: Cross-chain and same-chain swaps
- **Automatic Selection**: Best aggregator chosen automatically

### Trading Features
- **Token Selection**: Search and select from verified tokens
- **Price Impact**: Real-time price impact calculations
- **Slippage Settings**: Configurable slippage tolerance
- **Gas Estimation**: Automatic gas fee calculation

### Advanced Options
- **Limit Orders**: Set price targets for trades
- **DCA (Dollar Cost Averaging)**: Automated periodic purchases
- **Stop Loss**: Automatic sell orders at price thresholds

## How to Use

1. **Connect Wallet**: Ensure your wallet is connected to Avalanche network
2. **Select Tokens**: Choose input and output tokens from the dropdown
3. **Enter Amount**: Input the amount you want to swap
4. **Review Quote**: Check the exchange rate and fees
5. **Confirm Transaction**: Sign the transaction in your wallet

## Supported Tokens

The app supports all major tokens on Avalanche including:
- AVAX (Wrapped AVAX)
- GATOR (Gator token)
- USDC, USDT (Stablecoins)
- Major DeFi tokens (JOE, PNG, etc.)

## Safety Features

- **Transaction Preview**: See exactly what you're signing
- **Slippage Protection**: Configurable maximum slippage
- **Gas Limits**: Automatic gas limit estimation
- **Network Confirmation**: Avalanche network verification

## Fees

- **Network Fees**: Standard Avalanche gas fees
- **Aggregator Fees**: Minimal fees from swap aggregators
- **No Platform Fees**: GatorOS charges no additional fees

## Troubleshooting

### Common Issues
- **Insufficient Balance**: Ensure you have enough tokens + gas
- **Network Error**: Check Avalanche network connection
- **High Slippage**: Adjust slippage settings or wait for better liquidity
- **Transaction Failed**: Check gas prices and try again

### Support
For swap-related issues, check the Arena community or contact support.
