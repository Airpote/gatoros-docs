# Treasury App

The Treasury App provides comprehensive portfolio management and tracking for your Avalanche-based assets, including tokens, liquidity positions, and staked assets.

## Features

### Portfolio Overview
- **Total Balance**: Combined value across all assets
- **Asset Breakdown**: Individual token balances and values
- **24h Change**: Price changes over the last day
- **Portfolio Performance**: Historical performance tracking

### Asset Tracking
- **Token Balances**: All ERC-20 tokens in your wallet
- **LP Positions**: Liquidity pool shares and values
- **Staked Assets**: Staking positions and rewards
- **NFT Holdings**: NFT collection overview

### DeFi Positions
- **Yield Farming**: Active farming positions
- **Liquidity Mining**: LP rewards and APYs
- **Staking Rewards**: Claimable staking rewards
- **Protocol Interactions**: Transaction history

## How to Use

1. **Connect Wallet**: Link your wallet to view your portfolio
2. **View Overview**: See your total portfolio value
3. **Explore Assets**: Click on individual assets for details
4. **Track Performance**: Monitor price changes and yields
5. **Claim Rewards**: Harvest staking and farming rewards

## Supported Assets

### Tokens
- GATOR and other Arena tokens
- AVAX and WAVAX
- Stablecoins (USDC, USDT, DAI)
- Major DeFi tokens

### Liquidity Pools
- Trader Joe LP positions
- Pangolin LP positions
- Curve pools
- Custom AMM positions

### Staking
- Gator staking contracts
- Platform staking rewards
- Validator delegations

## Analytics

### Performance Metrics
- **Total Value Locked (TVL)**: Portfolio TVL tracking
- **Yield APY**: Annual percentage yields
- **Impermanent Loss**: IL calculations for LPs
- **Gas Efficiency**: Transaction cost analysis

### Historical Data
- **Price History**: Token price charts
- **Transaction History**: Complete on-chain activity
- **Reward History**: Claimed rewards over time
- **Portfolio Growth**: Value changes over time

## Security Features

- **Read-Only Mode**: View without transaction permissions
- **Data Privacy**: No private keys stored
- **Secure Connections**: Encrypted data transmission
- **Audit Trail**: Complete activity logging

## Integration

### API Endpoints
- `/api/treasury`: Portfolio data endpoint
- Real-time price feeds
- Transaction monitoring
- Balance updates

### Third-Party Services
- DexScreener for prices
- The Graph for DeFi data
- Covalent for transaction data
- Zapper for portfolio aggregation

## Troubleshooting

### Common Issues
- **Balance Not Showing**: Refresh wallet connection
- **Price Data Missing**: Check internet connection
- **LP Position Hidden**: Verify contract addresses
- **Rewards Not Updating**: Wait for block confirmation
